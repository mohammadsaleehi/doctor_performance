WP Performance Doctor helps website owners measure, diagnose, fix, and verify
WordPress performance. Inspection and diagnosis are read-only; optimizations
require explicit administrator confirmation.

== Description ==

WP Performance Doctor is a WordPress performance diagnostics and optimization
plugin. It inspects WordPress, PHP, database, server, and caching configurations,
identifies bottlenecks using a deterministic rule-based engine, and provides
actionable optimization recommendations.

== Installation ==

1. Upload the plugin to /wp-content/plugins/.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Visit Performance Doctor in the admin menu.
